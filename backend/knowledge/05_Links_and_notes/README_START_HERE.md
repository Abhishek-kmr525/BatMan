# Kalshi Study PDF Pack - Start Here

Created: 2026-04-27

This folder contains legally available PDFs and official public documents useful for studying Kalshi, prediction markets, event contracts, probability, statistics, and macro data sources.

Important: this pack is for learning. It is not financial advice, legal advice, tax advice, or a recommendation to trade.

## Suggested study order

1. `01_Kalshi_official/`
   - Start with `Kalshi_fee_schedule.pdf` and `Kalshi_member_agreement.pdf`.
   - Then read `Kalshi_rulebook_v1_24.pdf` sections on definitions, trading, prohibited transactions, position limits, clearing, settlement, and outcome review.
   - Read `Kalshi_Klear_rulebook_v1_3.pdf` if you want to understand clearing and member-fund mechanics.
   - Read `Kalshi_developer_agreement.pdf` before using the API.

2. `02_Prediction_markets_and_regulation/`
   - Read the CFTC fact sheet to understand what event contracts are, how regulated prediction markets differ from informal betting, and what risks and customer protections apply.

3. `03_Probability_statistics_forecasting/`
   - Use Grinstead and Snell for probability basics: conditional probability, expected value, variance, distributions, law of large numbers, central limit theorem, and Markov chains.
   - Use OpenIntro Statistics for practical statistics, sampling, inference, regression, and probability review.

4. `04_Macro_and_data_sources/`
   - Use the BEA NIPA Handbook if you want to trade or forecast GDP, PCE, national income, corporate profits, or macroeconomic releases.
   - Use the BLS CPI Handbook PDF as background for CPI methodology. Note: it is an older PDF; use the current BLS CPI website for the latest operational details.

5. `05_Links_and_notes/`
   - Contains official links, online resources that are not PDFs, and a list of copyrighted books not included in this ZIP.

## Key rule for Kalshi markets

Before any trade, read the market's full contract rules and identify the exact settlement source. A good forecast can still be a bad trade if you misunderstand the settlement rule, the timing, the source agency, the spread, or the fee.
